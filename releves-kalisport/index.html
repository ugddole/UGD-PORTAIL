Importez le relevé de la banque et l'export du journal Kalisport. L'appli repère les opérations déjà saisies et prépare un fichier avec seulement celles qui manquent, catégories comprises. Les fichiers restent dans votre navigateur : rien n'est envoyé.

  1. Dans Kalisport : Perso › Comptabilité › Journal, bouton …, puis Importer dans le journal.
  2. Choisissez le compte bancaire, puis le fichier. Associez les colonnes : Date, Libellé, Montant (positif = recette, négatif = dépense), puis Catégorie et Mode de règlement si la page les propose.
  3. Kalisport conseille de tester d'abord avec 5 à 10 lignes : décochez le reste ici, importez, vérifiez le journal, puis faites le reste.
